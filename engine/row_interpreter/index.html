Module row_interpreter 

Source
Expand description

Provides functions for encoding & decoding a row to/from binary This module contains the implementation for the row interpreter helper functions

These functions will convert an in memory representation of a data row (a Row instance) to and from a byte array as defined by the binary representation of a row.
